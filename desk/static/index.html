Each agent's steps land here, in log order. Click a step to read it.
Each agent is its own process. Kill sends SIGKILL; the supervisor starts a new one, the log redelivers what was unfinished, and a resolver killed after its checkpoint resumes from it. The resolver holds for 0s at the policy step so there is time to kill it mid-case. The policy pause is off, so the resolver usually finishes before you can kill it mid-case: restart the server with DESK_POLICY_PAUSE=8 to demo crash and resume.
